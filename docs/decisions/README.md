# decisions — why we chose what we chose

One short file per important decision, numbered: `001-tech-stack.md`, `002-…`.

Each file answers: **What did we decide? Why? What rules come with it?**
Six months from now, nobody remembers why — these files do.

Template:

```markdown
# 00X — Title
**Date:** · **Status:** Proposed / Accepted / Replaced by 00Y · **Decided by:**
## Decision
## Why
## Rules that come with it
```
